# Daftar pelanggan

Catat pelanggan hanya setelah keberadaan hubungan dan kebutuhan proyek
dikonfirmasi. Daftar ini tidak diisi dengan data contoh atau pelanggan fiktif.
Pemeriksaan repository saat dokumen ini dibuat tidak menemukan catatan
pelanggan yang dapat dikonfirmasi; itu tidak membuktikan bahwa tidak ada
pelanggan di luar repository.

## Status proyek

Gunakan salah satu status: **calon pelanggan**, **konsultasi**, **menunggu
persetujuan**, **pengerjaan**, **selesai**, atau **dibatalkan**. Gunakan status
pembayaran **Belum diketahui**, **Belum dibayar**, **Sebagian**, **Lunas**, atau
**Tidak berlaku** hanya berdasarkan konfirmasi; jangan mencatat rincian
rekening, transaksi, atau data keuangan sensitif.

## Format catatan pelanggan

Salin format berikut untuk pelanggan yang benar-benar ada. Gunakan ID pelanggan
unik seperti `PLG-001` (bukan nomor identitas pribadi), dan tautkan proyek
melalui ID proyek pada [daftar-proyek.md](./daftar-proyek.md).

```text
ID pelanggan:
Nama/nama panggilan:
Bisnis atau proyek:
Jenis website:
Tanggal mulai:
Target selesai:
Status proyek:
Status pembayaran (jika relevan):
Repository atau demo:
Kebutuhan yang dikonfirmasi:
Catatan dan tanggal pembaruan:
```

Belum ada entri pelanggan yang dikonfirmasi untuk dicatat.
