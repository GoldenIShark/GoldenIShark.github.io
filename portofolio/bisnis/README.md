# Business Portfolio

Portfolio website untuk kategori Bisnis.

## Teknologi
- HTML5
- CSS3
- JavaScript

## Struktur
```text
portofolio/bisnis/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── images/
    └── icons/
```

## Fitur
- Responsive
- Dark modern UI
- Scroll animation
- Project filter
- Counter animation
- Mobile navigation
- Loading animation

## Catatan
Website bersifat static/display-only dan tidak menggunakan backend.
